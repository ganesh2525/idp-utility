# IDP Utility Frontend

React application for managing hardware tokens.

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The app will run on http://localhost:3000

Make sure the backend server is running on http://localhost:5000

## Features

- View all hardware tokens (C100 and C200)
- Generate OTP for each token
- Real-time OTP display
- Responsive card-based UI
